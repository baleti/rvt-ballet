# Provenance of built-in tables / data
- rvtviewer/data/category_names.json: generated by tools/make_category_names.py from Revit-produced ground-truth dumps (rvt-research/gt4/*.tsv, "Name|BuiltInCategoryId" in E rows). Own copy; the viewer does not read the reader's category table.
- Parameter names/mappings: obtained through the reader (rvt_params.py -> map3_train.json, param_names.json). Checked 2026-10-11: all 2270 ids in param_names.json occur in the Revit gt4 dumps, but the reader's own provenance is session 176's responsibility. If they quarantine/replace those files the adapter follows via rvt_params.
- Geometry rules (wall/floor extents, sketches) are read from the .rvt records themselves.
