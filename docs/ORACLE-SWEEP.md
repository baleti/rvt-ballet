## Reading notes

* Volume is only compared for closed meshes (open shells have no origin-independent volume) and Revit solids that are exact duplicates (same volume, area, centroid, e.g. the three copies of a duct fitting) count once, because the viewer drops duplicate bodies.
* BaseRailing / StairsElement / StairsRun / StairsSupport: Revit's bounding box of the host element includes its child elements (top rail, balusters), so a low IoU for the host mesh alone is expected; judge them by their children (TopRail, ...). 2024_railing_base reads 0.32, the same railing shifted 0.95.
* Doors (and windows): the Revit BoundingBoxXYZ of a door includes the open-leaf swing symbol (2D curves), so the bbox IoU of the leaf + frame mesh can read 0.2 while the surface area matches exactly (c5-geometry, 2026-10-17): compare by area / face count, not by the box.
* Hub, ReferencePoint, BasePoint, CoordinateSystemDisplayElem, LineLoad, BoundaryConditions, Viewer3d, ProfileRefPlane are not solids: box only by design.
